# Workflows Disponibles

Esta tabla contiene todos los workflows disponibles en el proyecto, organizados por categoría.

## Tabla de Workflows

| Comando | Descripción |
|---------|-------------|
| `/ai-brainstorm` | Sesión de lluvia de ideas colaborativa usando Gemini, Codex y Claude Code CLI - tres IAs intercambian opiniones para generar ideas (los modelos no disponibles se omiten automáticamente) |
| `/chain-of-thought` | Técnica de Cadena de Pensamiento (CoT) que mejora las capacidades de resolución de problemas complejos estructurando los procesos de pensamiento de manera similar al razonamiento lógico humano |
| `/check-env` | Verifica el entorno de desarrollo actual (SO, Node.js, Git, etc.) y muestra información del sistema |
| `/claudecode` | Invoca Claude Code CLI para análisis de código, modificaciones y consultas |
| `/codex` | Invoca Codex CLI para análisis de código y revisión técnica |
| `/concept-mapping` | Técnica de Mapeo de Conceptos que descubre conexiones entre diferentes dominios de conocimiento para derivar ideas creativas |
| `/confidence-threshold` | Técnica de Umbral de Confianza que previene alucinaciones de LLM y evalúa explícitamente la fiabilidad de las respuestas |
| `/deep-debug` | Flujo de trabajo de depuración profunda para encontrar las causas raíz de errores complejos |
| `/deliberation` | Técnica de Deliberación que sigue un proceso de pensamiento sistemático y multifacético para análisis profundo y toma de decisiones |
| `/gemini` | Invoca Gemini CLI para consultas y generación de resultados |
| `/mcp-install` | Instala un nuevo servidor de Model Context Protocol (MCP) usando Node.js |
| `/multi-perspective` | Técnica de Múltiples Perspectivas que analiza problemas complejos desde varios puntos de vista de las partes interesadas para proporcionar una perspectiva equilibrada |
| `/persona` | Activa personas especializadas de desarrollador para asistencia enfocada |
| `/persona-activations` | Mensajes de activación de personas para modos especializados de desarrollador |
| `/red-team` | Técnica de prompting Red Team que desafía las respuestas de LLM para impulsar respuestas más profundas y precisas, e identificar posibles vulnerabilidades o sesgos |
| `/refactor` | Flujo de trabajo sistemático de refactorización para mejorar la calidad del código |
| `/task` | Procedimiento estándar para iniciar nuevas tareas de desarrollo |

## Categorías

### 🤖 Herramientas de IA
- `/ai-brainstorm` - Colaboración entre múltiples IAs
- `/claudecode` - Asistencia con Claude Code
- `/codex` - Análisis con Codex
- `/gemini` - Consultas con Gemini

### 🧠 Técnicas de Prompting
- `/chain-of-thought` - Razonamiento paso a paso
- `/concept-mapping` - Mapeo de conceptos entre dominios
- `/confidence-threshold` - Evaluación de confiabilidad
- `/deliberation` - Análisis sistemático profundo
- `/multi-perspective` - Análisis desde múltiples perspectivas
- `/red-team` - Desafío crítico de respuestas

### 🛠️ Desarrollo y Debugging
- `/check-env` - Verificación del entorno
- `/deep-debug` - Depuración profunda
- `/refactor` - Refactorización sistemática
- `/task` - Gestión de tareas de desarrollo

### 👤 Personas Especializadas
- `/persona` - Activación de personas especializadas
- `/persona-activations` - Mensajes de activación

### ⚙️ Configuración
- `/mcp-install` - Instalación de servidores MCP

## Uso

Para usar cualquier workflow, simplemente escribe el comando correspondiente en el chat. Por ejemplo:

```
/task
```

Esto activará el workflow correspondiente y te guiará a través del proceso.
