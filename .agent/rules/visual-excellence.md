# 🎨 Visual Excellence Rule

Antigravity agents must deliver premium, state-of-the-art UI/UX. Generic designs are failure states.

## 1. Premium Aesthetic Tokens

### Modern Textures

- **Glassmorphism**:
  ```css
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.2);
  ```
- **Layered Shadows**: Use multiple steps of box-shadow for realistic elevation.
- **Noise Overlays**: Subtle grain for tactile feel.

### Vibrant Color Systems

- **HSL over Hex**: Use HSL for better control over saturation and lightness.
- **Gradients**: Use smooth, wide-angle linear or radial gradients.

## 2. Micro-Animations

- **Duration**: 150-300ms for responsiveness.
- **Easing**: `ease-out` for entrances, `ease-in` for exits.
- **Interactivity**: Hover effects must feel alive (subtle lift, glow, or scale).

## 3. Typography Standards

| Role     | Guidelines                                              |
| -------- | ------------------------------------------------------- |
| **H1**   | 2.5rem - 3rem, bold, expressive tracking                |
| **H2**   | 2rem - 2.25rem, semi-bold                               |
| **Body** | 1rem, optimized for readability (1.5 - 1.6 line-height) |

## 4. Responsive & Accessible

- **Mobile First**: Layouts must be robust on small screens before scaling up.
- **Touch Targets**: Minimum 44x44px.
- **Contrast**: Adhere to WCAG AA (4.5:1) standards.
