# ✍️ Copy Editing Rule

Guidelines for systematic improvement of marketing copy through focused passes.

## 1. The Seven Sweeps Process

When editing, address each dimension sequentially:

1.  **Clarity**: Sentences must be immediately understandable. Highlight and fix confusing structures or jargon.
2.  **Voice & Tone**: Ensure consistency. Smooth out unintentional mood shifts.
3.  **So What**: Test every claim. If it doesn't answer "why should I care?" with a benefit, add a "which means..." bridge.
4.  **Prove It**: Substantiate every superlative or claim with specifics (names, numbers, logos).
5.  **Specificity**: Replace vague verbs (improve, optimize) with concrete outcomes. Quantify when possible.
6.  **Heightened Emotion**: Identify flat sections. Paint "before" and "after" states vividly.
7.  **Zero Risk**: Address hesitations near CTAs. Add risk reversals (guarantees, trials).

## 2. Word-Level Controls

| Cut (Filler/Weak)         | Replace with Stronger |
| :------------------------ | :-------------------- |
| very, really, incredibly  | [Stronger adjective]  |
| just, actually, basically | [Remove]              |
| in order to               | to                    |
| utilize, implement        | use, set up           |
| innovative, robust        | new, strong           |

## 3. Structural Guidelines

- **Sentence Length**: Mix short and long. Front-load important information. Keep most under 25 words.
- **Paragraphs**: 2–4 sentences for web. One topic per paragraph.
- **Active Voice**: Prefer active constructions over passive ones.

### Collaboration Protocol

1.  **Identify need**: Is the issue a wording tweak (Editing) or a structural change (Page CRO)?
2.  **Consult**: Use `/ask-persona [name] "[query]"` for specialized input.
3.  **Loop Back**: Always re-verify previous sweeps after integrating new insights.
