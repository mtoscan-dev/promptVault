# 🎨 Brand Guidelines Rule

Use this rule to apply Anthropic's official brand identity and style resources.

## 1. Brand Palette

| Role                   | Color      | Hex Code  |
| ---------------------- | ---------- | --------- |
| **Primary Text**       | Dark       | `#141413` |
| **Primary BG**         | Light      | `#faf9f5` |
| **Secondary Elements** | Mid Gray   | `#b0aea5` |
| **Subtle BG**          | Light Gray | `#e8e6dc` |
| **Primary Accent**     | Orange     | `#d97757` |
| **Secondary Accent**   | Blue       | `#6a9bcc` |
| **Tertiary Accent**    | Green      | `#788c5d` |

## 2. Typography

- **Headings**: Poppins (fallback: Arial)
- **Body Text**: Lora (fallback: Georgia)
- **Note**: Apply Poppins to headings 24pt and larger.

## 3. Visual Application

- **Hierarchy**: Preserve strict text hierarchy and formatting.
- **Contrast**: Automatically select light/dark text based on background color.
- **Accents**: Cycle through orange, blue, and green for non-text shapes to maintain interest.

## 🔗 Collaboration Permissions

| Persona           | Use Case                                            |
| ----------------- | --------------------------------------------------- |
| `frontend-design` | Direct implementation of brand styles in CSS/Markup |
| `copywriting`     | Ensuring brand voice matches visual appearance      |
